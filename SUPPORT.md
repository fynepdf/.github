# Getting help

- **Using one of the open-source projects** (fynepdf-pdfa, fynepdf-grayscale, wrapguard): start with the project's README, then open an issue in its repository if you're stuck or think you've found a bug.
- **A security problem:** report it privately, as the [security policy](https://github.com/fynepdf/.github/blob/main/SECURITY.md) explains.
- **fynepdf.com, the FynePDF desktop app, your account or billing:** these aren't handled on GitHub. Email [support@fynepdf.com](mailto:support@fynepdf.com) or use the [contact page](https://fynepdf.com/contact-us).
