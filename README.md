# fynepdf/.github

Shared files for the [FynePDF organization](https://github.com/fynepdf):

- [`profile/README.md`](profile/README.md) is the organization's profile page.
- [`SECURITY.md`](SECURITY.md), [`CONTRIBUTING.md`](CONTRIBUTING.md), [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md), [`SUPPORT.md`](SUPPORT.md), the issue forms and the pull request template in [`.github/`](.github) apply to every public FynePDF repository that doesn't have its own.
